# Essay page assets — provenance

These fragments are vendored copies, not sources of truth:

- `scatter.svg` — the 27-comparison calibration scatter, extracted from
  `site/below-zero/draft.html` (generated by `build_draft()` in
  `scripts/build_site.py` from the committed CSVs).
- `prompt_reliability.svg`, `train_reliability.svg` — the two reliability
  figures extracted from `site/below-zero/brief-table.html` (same generator).
- `scatter.css`, `reliability.css` — the CSS rules those SVGs depend on,
  extracted from the same two pages' style blocks.
- `page_behaviors.js` — the shared scroll-progress + table-edge-fade script
  copied from `brief-table.html`.

If `build_site.py` regenerates those pages with different numbers, re-extract
(or re-point `scripts/build_essay_page.py` at the live pages). The dose-
evolution chart is NOT vendored: `build_essay_page.py` draws it directly from
`data/processed/seed_replication_knowledge.csv`.
